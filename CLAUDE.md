# Claude: read AGENTS.md

**Never commit.** Don't run `git commit`, `git add`, `git push`, `git tag`, or any other git command that stages, commits, rewrites or discards changes. Leave every change unstaged in the working tree; the maintainer reviews it and commits it himself with his own message. Read-only git (`status`, `diff`, `log`, `show`) is fine.

The full rules and the project orientation are in AGENTS.md. When you work on a card, also read `cards/<card>/AGENTS.md`.
